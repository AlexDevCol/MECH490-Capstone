# BB01 Robot

BB01 is a 6 DOF robotic arm designed for the MECH490 Capstone project. It is fully integrated into the parametric architecture and can be used alongside Panda and Rob robots.

> **Status: Fully Integrated**
> 
> BB01 is fully integrated with ros2_control, MoveIt, and Gazebo simulation.

## Overview

| Property | Value |
|----------|-------|
| **Name** | BB01 |
| **DOF** | 6 |
| **Design** | Custom capstone design |
| **CAD Source** | SolidWorks |
| **URDF Export** | SolidWorks to URDF Exporter |
| **Status** | Fully Integrated |

## Package Structure

The BB01 robot is part of the unified `robot_description` package:

```
src/robot_arm/robot_description/
└── robots/
    └── bb01/
        ├── urdf/
        │   ├── bb01.urdf.xacro        # Main robot description
        │   ├── bb01.urdf               # Generated static URDF
        │   └── control/
        │       ├── gazebo_sim_ros2_control.urdf.xacro
        │       └── bb01_ros2_control.urdf.xacro
        └── meshes/                      # STL mesh files
            ├── base_link.STL
            ├── link_1.STL
            ├── link_2.STL
            ├── link_3.STL
            ├── link_4.STL
            ├── link_5.STL
            └── link_6.STL
```

MoveIt configuration is in the unified `robot_moveit_config` package:

```
src/robot_arm/robot_moveit_config/
└── robots/
    └── bb01/
        └── config/
            ├── bb01.srdf
            ├── kinematics.yaml
            ├── joint_limits.yaml
            └── ...
```

## ros2_control Configuration

BB01 has full ros2_control integration for Gazebo simulation.

### Hardware Interface (Simulation)

```xml
<ros2_control name="BB01System" type="system">
  <hardware>
    <plugin>gz_ros2_control/GazeboSimSystem</plugin>
  </hardware>
  <!-- Joint interfaces for all 6 joints -->
</ros2_control>
```

### Controllers

| Controller | Type | Joints |
|------------|------|--------|
| `joint_state_broadcaster` | Broadcaster | All |
| `joint_trajectory_controller` | JointTrajectoryController | All 6 joints |

| Pipeline | Description |

## Usage

### Visualize Robot Only

```bash
ros2 launch robot_description display.launch.py robot:=bb01
```

### Launch in Gazebo

```bash
ros2 launch robot_gazebo simulation.launch.py robot:=bb01
```

### Launch with MoveIt

```bash
# Terminal 1
ros2 launch robot_gazebo simulation.launch.py robot:=bb01 use_rviz:=false

# Terminal 2 (after ~15 seconds)
ros2 launch robot_moveit_config move_group.launch.py robot:=bb01
```

### Using Bringup Script

```bash
./run_script.sh
# Select robot: bb01
# Select script: Gazebo And Moveit
```
