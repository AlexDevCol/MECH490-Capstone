# BB01 Robot

BB01 is a new 6 DOF robotic arm designed for the MECH490 Capstone project. It will replace the Rob (Moveo-based) robot as the main capstone robot.

> **Status: Under Construction**
> 
> This robot is currently being integrated into the project. Many features are not yet implemented.

## Known Issues

### 1. Mesh Path References

**Problem:** The URDF references meshes with incorrect package name:

```xml
<!-- Current (incorrect) -->
<mesh filename="package://BB01_URDF/meshes/base_link.STL" />

<!-- Should be -->
<mesh filename="package://bb01_description/meshes/base_link.STL" />
```

**Fix needed in:** `urdf/BB01_URDF.urdf.xacro`

### 2. Joint Limits Not Configured

**Problem:** All joints have zero limits:

```xml
<limit lower="0" upper="0" effort="0" velocity="0" />
```

**Required:** Determine actual joint limits from CAD model or physical constraints.

### 3. No ros2_control Integration

**Problem:** The URDF lacks ros2_control hardware interface definitions.

**Required files to add:**
- `urdf/control/bb01_ros2_control.urdf.xacro`
- `urdf/control/gazebo_sim_ros2_control.urdf.xacro`

### 4. No MoveIt Configuration

**Problem:** No `bb01_moveit_config` package exists.

**Required:** Run MoveIt Setup Assistant to generate configuration.

### 5. Joint Axis Alignment

**Problem:** Some joint axes have non-unit values (from CAD export):

```xml
<axis xyz="0.0010187 -0.0029659 1" />  <!-- Should be normalized -->
```

**Recommended:** Normalize or simplify axis definitions.
